# Navegação inicial do VINX ERP

## Início

Depois de entrar, a página **Início** reúne as empresas que você está autorizado a consultar. A leitura padrão é **Todas as empresas autorizadas**. As cores e símbolos ajudam a identificar cada empresa, mas não mudam permissões nem escolhem uma empresa para ações.

A estrutura em evolução inclui destinos de módulos em preparação. Paguai,
Atendimento, Kanban e Pessoas explicam o escopo futuro, mas ainda não exibem
dados nem ações operacionais.

## Navegação e ajuda

Em telas maiores, use a navegação lateral. Em telas menores, escolha **Abrir navegação** no cabeçalho. Use **Ajuda** para voltar a estas orientações. O link **Pular para o conteúdo principal** permite chegar diretamente ao conteúdo ao navegar pelo teclado.

## Aparência e densidade

Abra **Abrir preferências visuais** no cabeçalho para escolher **Tema: claro**
ou **Tema: escuro**, além de densidade confortável ou compacta. Essas escolhas
alteram somente a apresentação da interface.

## Sair

Escolha **Sair** no cabeçalho quando terminar. Se a saída não puder ser concluída, a aplicação continua aberta e mostra uma mensagem para que você tente novamente.
