# Preferências visuais

Use o botão **Abrir preferências visuais** para escolher o tema e a densidade
da interface.

## Tema

- **Tema: claro** mantém a interface clara.
- **Tema: escuro** mantém a interface escura.

## Densidade

- **Confortável** deixa mais espaço entre os elementos.
- **Compacta** reduz os espaçamentos sem reduzir controles abaixo de 24 CSS px.

O navegador pode restaurar essas escolhas depois de recarregar a página. Elas
alteram somente aparência: não criam sessão, não mudam permissões e não
selecionam uma empresa.

Cada empresa recebe uma cor auxiliar estável para facilitar leitura de listas
multiempresa. Essa cor é identidade visual, nunca evidência de acesso.

## Ajuda

A central **Ajuda** repete estas orientações para uso durante a navegação.
