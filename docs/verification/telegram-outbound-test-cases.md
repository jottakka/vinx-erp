# Casos públicos — Telegram Bot API outbound (#308)

Esta fatia entrega somente envio de texto aprovado pelo WorkerHost. Os envios
configurados usam `FakeTelegramBotHandler`; a factory padrão sombreia todas as
variáveis `TELEGRAM_*` e instala um handler local que falha antes de qualquer
rede. Inbound, webhook, anexos, comandos e resposta automática permanecem
fora do escopo.

No cenário de sucesso, o log capturado exclui token, URI do Bot API, corpo,
endereço, texto e detalhe remoto; na DLQ de retry, payload e headers são
redigidos e a serialização exclui o ID real, token, endereço e texto do caso.
`delivered` significa aceite do provider, não prova de leitura humana.
